# ADR 0010 - Rename `toolkit` to `formwork` in code

Status: **accepted** (Rob, 2026-10-01). Closes backlog B21. Foundation version
0.3.0-alpha.1.

## Context

ADR 0008 named the product Formwork but kept the technical names (`toolkit`
CLI, `toolkit_*` packages, `.toolkit/` state folder) for a separate change.
Renames get more expensive with every adopter, and today there are none. The
first PyPI release (ADR 0009) would freeze whatever names exist then.

## Decision

Rename everything a person types, reads, or finds on disk:

| Before | After |
| --- | --- |
| `toolkit_engine`, `toolkit_cli`, `toolkit_wizard` | `formwork_engine`, `formwork_cli`, `formwork_wizard` |
| `python -m toolkit_cli`, `prog="toolkit"` | `python -m formwork_cli`, `formwork` |
| Workspace state folder `.toolkit/` | `.formwork/` |
| `kind` values `toolkit-*` (reports, manifest, marker) | `formwork-*` |
| Report field `toolkit_version` | `formwork_version` |
| Wizard header `X-Toolkit-Token` | `X-Formwork-Token` |
| Live probe protocol `toolkit-live-probe-v1` | `formwork-live-probe-v1` |
| Add-in build codes `TKADDIN00x`, MSBuild targets `ToolkitCheck*` | `FWADDIN00x`, `FormworkCheck*` |
| "Generated by toolkit_engine" in generated files | "Generated by formwork_engine" |

### Compatibility

- **Existing workspaces keep working.** The engine reads a pre-0.3 workspace
  whose state lives in `.toolkit/`, and accepts the old `kind` values there.
  - A dry run reports the move (`plan.state_migration`, info diagnostic
    `workspace.state-migration`) and writes nothing.
  - The first applied render renames `.toolkit/` to `.formwork/` in one
    directory rename, rewrites the marker's `kind`, then applies as usual.
  - A conflict blocks the move along with everything else.
  - If both folders exist, the render refuses with
    `workspace.state-ambiguous` rather than guess.
- **The old command keeps working for one release.** `python -m toolkit_cli`
  forwards to `formwork_cli` and prints a notice. The alias is removed in
  0.4.0.
- **`.toolkit/` stays reserved.** No adapter or override may write there, in
  any letter case.
- **Generated managed files change**: their comments, the AGENTS.md and README
  commands, and the add-in diagnostics. The next render shows them as updates.
  Firm-owned and seed files are untouched.

## Unchanged on purpose

- The add-in GUID namespace seed (ADR 0008). Changing it would re-roll every
  generated add-in identity.
- Historical documents (handoffs, reviews, ADRs 0001-0008). They record the
  names in use at the time.
- The ordinary English word "toolkit" in prose and in the sample button text
  ("your pyRevit toolkit").
- Manifest and marker `schema_version` stay 1. Only `kind` changed, and reads
  accept both values.

## Consequences

- Report consumers must read `formwork_version`. No outside consumers exist.
- The live probe protocol changed on both ends, which ship together in this
  repository.
- Removing the `toolkit_cli` alias is backlog B23 (0.4.0). The legacy-folder
  read is small and stays until no pre-0.3 workspace is known to exist.
